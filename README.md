# Speed Reading Tool
Small Tampermonkey script allowing to read paragraphs on websites faster. [Watch Demo](https://youtu.be/vXPNAT_dkNk)

# Installation

To use this script you will need [Tampermonkey extension](https://www.tampermonkey.net/) in your browser in order to inject custom scripts. 

If you have Tampermonkey installed you just simply have to add new script and copy and paste content from `SpeedReadingTool.js` file there.

# How to use
When you hold Alt and click on any text on page, small window should show up in the middle iterating through words. By focusing your eyes on red letter in the middle you will be able to get general idea what this text is about.

You can cancel it by clicking anywhere on the page. 

# Customization

You can change speed by changing `INTERVAL` value inside script _(How long word is displayed in miliseconds)_

You can also edit style values if you prefer different colors etc.
